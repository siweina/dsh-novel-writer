# 小说写作助手 (novel-writing)

## 章节库约定

- 所有小说章节存放在工作区 `novels/<书名>/` 文件夹下，每章一个 Markdown 文件，命名如 `第01章.md`、`第02章.md`。
- 优先使用专用工具 `novel_books` / `novel_chapters` / `novel_read` 浏览与阅读；也可用 `glob`/`read` 直接查看。

## 分析工作流

1. `novel_books` 找到用户的作品；
2. `novel_chapters` 查看章节结构与各章字数；
3. `novel_read` 逐章通读（长章节用 offset/limit 分段读完）；
4. `novel_keywords` 提取高频关键词（中文词组/单字 + 英文词），作为词汇偏好与意象母题的证据；
5. 输出分析，至少覆盖三方面：
   - **剧情脉络**：冲突、转折、悬念、伏笔、人物关系与目标；
   - **写作手法**：叙事视角、节奏、对话、环境与细节描写、比喻意象、留白；
   - **关键词与意象**：结合 novel_keywords 的结果，指出作者反复使用的词汇与意象，并引用具体章节佐证。

## 句式模式分析（v0.5.0 合并版）

- 工具 `novel_sentence_analysis`：九类句式（陈述/环境/心理/对话/疑问/反问/感叹/祈使/省略留白）——
  - 分布：比例、句数、平均句长、例句；
  - 排列：句式转移、2/3 连句模板、段首/段尾句式、按章节的压缩节奏序列（S×8 ENV×2 PSY×3…）；
  - 节奏：句长均值/中位数、短句/长句占比；
  - 主观情感：情感词典（喜/怒/哀/惧/惊）+ 强度副词加权 → 主导情绪、情绪分布、情感曲线、主观性指数；
  - 风格指纹 + 节奏建议（guidance）。
- 工具 `novel_sentence_config`：查看/修改开关（`enabled` / `autoAnalyze`）。
- 开关默认开启；统一在 Web GUI 侧边栏「句式分析」面板调整（设置 > 插件配置 仅显示状态），也可用 novel_sentence_config。
- 使用规则：
  - 动手前先调用 `novel_sentence_config` 查看状态；
  - `enabled=false` 时 novel_sentence_analysis 会返回关闭状态，不要强行分析；
  - `autoAnalyze=true` 时分析作品应主动附带句式分析；false 时仅在用户明确要求时调用；
  - **风险约束**：句式模式是参考节奏而非模板套用；若机械复刻导致僵硬，必须优先回归自然表达。

## 原稿件批量导入（v0.4.0 合并）

- 工具 `novel_import`：扫描存放多本小说稿件的文件夹（`src`），自动识别书名/章号并分组；
- 先以 `scan` 模式查看分组建议；发现异名同书时用 `book` 参数强制合并；
- 确认后以 `apply` 模式导入到 `novels/<书名>/`（默认复制，`move` 可移动）。

## 续写工作流

1. 先通读最近的章节（必要时读完全书），保持：人物设定、时间线、情节伏笔、文风、已提炼的关键词一致；
2. 动笔前简述：上一章结尾状态 → 本章目标 → 写作计划；
3. 用 `novel_new_chapter` 创建新章节文件，或直接用 `write` 工具写入 `novels/<书名>/第NN章.md`；
4. 正文用中文，保持与原文一致的叙事风格与细节密度；
5. 若句式分析已启用且 autoAnalyze=true，续写时可参考句式指纹与节奏序列保持节奏一致，但僵硬时必须回归自然表达。

## 注意事项

- 用户放入章节文件的方式不限：可以自己复制进文件夹，也可以让 AI 用 `write`/`edit` 工具创建，或用 novel_import 批量导入。
- 分析结果与续写正文都应使用中文呈现。
